  - 格式：PCM16 WAV / 48kHz / 立体声。
- 正式逐句文件落点（按锁定文档）：`E:\视频制作专用\AI短剧工厂\EPXX\05_配音\01_正式语音素材\{林晚,丈夫}\EPXX_NN_角色_台词_v1.wav`。
- **缺文件处理**：某句正式配音不存在 → 报告"缺少剪映正式配音"并**停止流程**，绝不自动调用旧 AI 配音补位。

### 1.5 视频合成规则（S8/S9 标准化，参数化 EP 编号/帧数/分辨率）
- 首帧命名：`EPXX_NN.png`（正式）｜`EPXX_NN_v2.png`（重做顶替）｜`EPXX_NN_old.png`（被替旧版归档，不占正式名）。**严禁 `.png.png` 双后缀**。
- 视频镜头：`EPXX_NN_video_vX.mp4`，规格 1080×1920 / 24fps / 121 帧 / 5.0417s / 无音轨（VideoGen 统一产出，未重生成即沿用）。
- 粗剪：`ffmpeg -f concat -safe 0 -i list.txt -c copy` 原样拼接，不裁剪。
- 去水印：`delogo=x=830:y=1840:w=244:h=78`（首帧级 `x=742:y=1482:w=120:h=52`）。坐标来自 EP01/EP03 实测"视频由AI生成"位置，换生成器须重新抽帧定位。
- 渐黑：VideoGen 常不渲染"画面渐黑" → 补 `fade=t=out:st=<总时长-0.8>:d=0.8`（与音频主淡出同步）。
- 字幕烧录：cd 进 `07_字幕/` 用**相对路径** `subtitles=EPXX_字幕.ass`（`fontconfig` 自动找 Microsoft YaHei；`fontsdir` 参数会被 shell 打碎，去掉）；长句手动 `\N` 分行 ≤17 字/行，底边距 90→40 避开去水印区。
- 音频 mux：`-c:a aac -b:a 192k -ar 48000 -ac 2`。
- 成片命名约定（待统一，见 §3 待办）：建议 `_v1`=检查版(带水印)、`_v2`=发布版(去水印)。注意 EP03 误用 `_v1` 作发布版，需标准化。
- 字幕铁律（规则#4）：**不生成手机/本子中的可读中文文字**（金额、记账、招聘软件等），含义由旁白+动作镜头传达。

## 2. 可变部分（每集替换）

| 维度 | 替换内容 | 来源 |
|---|---|---|
| 剧本/分镜 | `EPXX_剧本.md` + `EPXX_正式分镜表.md`（8 列 + S0 检查 + 连续性基线 + 待确认事项） | 编剧/分镜表 |

## 4. 下一步自动化改造方案

**原则：不重复造轮子。** `AI短剧自动出片Skill_v1.0.md`（S0–S9）已是流程主控；本规划 = 其"变量清单 + 脚本参数化"补充。建议在该 Skill 上加 §11「配置驱动改造」，而非另起炉灶。

### 4.1 脚本参数化（最小改动）
- **`build_audio.py` → `build_audio_episode.py` + `episode_config.yaml`**
  - 可抽取变量：`VO_DIR`、`OUT_WAV`、镜头表 `SHOTS[{name, dur, voices:[{file, offset}], bed}]`、环境床预设（home/old）、BGM 配置、delogo/fade 参数。
  - 现状：479 行脚本已用 `VO_DIR` + `SHOTS` 表驱动（`EP01_NN_角色.wav` 按文件名匹配、按 offset 落点），改造量小——把硬编码表外置为 YAML 即可。
- **配音读取规则脚本化**：新增 `verify_voices.py`——读取 canonical 目录 WAV，校验存在性 + 标准音色 SHA-256，缺失即报错停止（落实 voice_pipeline.md 第 3 条）。
- **视频合成脚本化**：把 S8/S9 的 concat/delogo/fade/subtitles/mux 固化为 `compose_episode.py`，入参仅 EP 编号、帧数、分辨率。

### 4.2 配置驱动总控
新建 `episode_config.yaml` 每集一份，声明：
```yaml
ep: EP02
shots: 12
frame_per_shot: 121
roles:
  linwan: {ref: 01_角色参考图/林晚/林晚_01_固定标准角色图_v2.png, costume: LW-C01}
  husband: {ref: 01_角色参考图/丈夫/丈夫_01_固定角色参考图.png}
continuity:   # 跨镜/跨集锚点
  shoes: 深棕平底鞋
  bag: 棕色单肩包(左肩)
  suitcase: 深灰软壳行李箱
  room: 老房子客厅
voice:
  standard_check: sha256  # 校验林晚/丈夫标准 WAV
  source_dir: E:\视频制作专用\AI短剧工厂\EP02\05_配音\01_正式语音素材
subtitle_rule4: true   # 不生成屏内可读文字
```
Skill 各阶段（S3 首帧 / S4 视频 / S5 配音 / S7 字幕 / S9 合成）读取该配置自动取变量。

### 4.3 自检清单复用
直接复用 Skill 现有 5 类自检（角色连续性、动作镜头验收、字幕规则#4、水印、音频零削波），无需重写。

### 4.4 改造步骤（建议顺序）
1. 先裁定 §3 范围（重制 EP02 还是做 EP04）。
2. 抽取 `episode_config.yaml`  schema（先 EP01 反推，再 EP02 验证）。
3. 改造 `build_audio.py` → 配置驱动 + `verify_voices.py`。
