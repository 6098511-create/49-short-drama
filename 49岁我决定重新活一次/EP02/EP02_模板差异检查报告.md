## 二、需要修改的项 ⚠️

### 🔴 P0 — 配音引擎违规（核心阻断项）
- **事实**：`05_配音/01_正式语音素材/` 现有 3 个 WAV（`EP02_06_林晚.wav`、`EP02_10_林晚旁白.wav`、`EP02_12_林晚旁白.wav`）按 `制作状态.md` S5 记录为 **F5-TTS** 合成，并已进入 v2/v3 成片音频。
- **违反**：用户确认规则 1「正式成片禁止 F5-TTS / Kokoro 等 AI 音色，统一用剪映人工录制 WAV」。
- **动作**：在剪映按 3 条台词重新人工录制 → 裁尾 → 重混音 → 重烧成片；现有 F5-TTS WAV **归档为历史测试资产保留**（不删）。
- **影响**：需重做 S5–S9 音频部分 + 成片重烧（视频镜头/首帧不动）。

### 🟠 P1 — 86,000 元字幕未按 EP01「小字」处理
- **事实**：EP02 字幕第 20 行 `可支配积蓄 86,000 元` 使用 **Dialogue 样式（56px / 底部 MarginV 300）**。
- **要求**：用户确认「按 EP01 规则：小字显示、不遮挡画面、不做大标题」。EP01 同款为 **Note 样式（42px / MarginV 470 / 蓝色 &H0078C8FF）**，位置更高、字号更小、不挡主体。
- **动作**：在 `EP02_字幕.ass` 增加 EP01 同款 `Note` 样式，将该行改为 Note 小字；或直接引用 EP01 的 Note 定义。
- **关联文案不一致（同 P1）**：EP01 写「**个人**积蓄 86,000元」，EP02 写「**可支配**积蓄 86,000 元」。建议统一为「个人积蓄 86,000元」以跨集一致（亦贴合用户本次措辞）。

### 🟡 P2 — 屏幕文字字幕的「无对应声音」例外需注明
- **事实**：EP02 字幕 05（女儿微信「妈，你到哪儿了？」）、08（86,000 元）**无对应 VO 文件**，属「画面可读文字改字幕呈现」的既定方案（分镜明文）。
- **风险**：模板 §4 第 2 项「每一句字幕必须对应声音」会将其判为异常。
- **动作**：在字幕文件头注释中明确「05/08 为屏幕文字字幕，故意无 VO，属规则例外」，避免后续 QC 误报。

### 🟢 P3 — 母带位深 / 定版管理（低优先）
- **事实**：母带 `EP02_混音_母带.wav` 为 **PCM_24**；模板 §5 规定 16bit。48k/立体声已符合，24bit 无害且质量更高。
- **动作**：建议模板放宽到「16/24bit 均可」，或输出时转 16bit；属文档对齐，非成片缺陷。
- **定版管理**：当前 `v2`（发布版，60.5s）与 `v3`（修正版非定版，61.9s）并存。建议明确哪一版为当前定版，避免混淆（历史存档保留即可）。
