# AI短剧自动生产模板 v1

> 来源：EP01 已验证的最终生产流程（v3 定版，60.50s / 1452 帧 / 1080×1920 / 48kHz）。
> 适用范围：EP02 及后续每一集。
> 配套文件：`episode_config.yaml`（只改「集数 / 剧本 / 镜头数量 / 配音文件」四项是最小变量集）。
> 本模板不依赖任何 AI 配音引擎——正式声音一律由人工在剪映录制，AI 音色禁止进入成片。

---

## 一、标准目录结构

每一集统一放在 `EPXX/` 下，目录名与编号固定，后续脚本全部按此约定读写：

```
EPXX/
├── 01_剧本/                # 剧本 .md（台词唯一真源，逐字对应字幕）
├── 02_分镜/                # 分镜表 .md（8 列：镜号/景别/画面/台词/时长/音乐音效/备注/连续性）
├── 03_首帧/                # 每镜首帧 PNG，命名 EPXX_01.png … EPXX_12.png（单后缀，禁 .png.png）
├── 04_视频镜头/            # 每镜视频 MP4，命名 EPXX_0X_video_v1.mp4，统一 121 帧 @24fps
├── 05_配音/
│   └── 01_正式语音素材/     # 剪映导出、裁尾后的扁平 WAV（角色_镜号_台词.wav）
├── 06_音频工程/            # 混音工程输出：人声+环境床+音效+BGM 合成母带 WAV
├── 07_字幕/                # EPXX_字幕.ass（特效师/烧录用，唯一字幕真源）
├── 08_粗剪预览/            # 仅 concat 视频（未烧字幕/未混音），供分段预审
└── 09_最终成片/            # EPXX_最终成片_vX.mp4（发布版）
```

**与 EP01 实际差异（已修正为规范）**
- EP01 错把粗剪预览编号为 `05_粗剪预览`、混音目录名为 `06_音乐音效`、剪映素材为 `08_剪映素材`；自 EP02 起统一为 `08_粗剪预览` / `06_音频工程`。
- 配音正式素材固定落在 `05_配音/01_正式语音素材/`（扁平化），不再保留 `00_音色试听` 等 AI 时代空目录。

## 二、自动生产流程

输入：**剧本** → 自动串联下列 10 个阶段。除「首帧生成 / 视频生成」需调用图像、视频生成工具外，其余阶段均可脚本化。

```
剧本 ──①解析──▶ 剧本解析 ──②分镜──▶ 分镜表 ──③清单──▶ 镜头清单
   │                                                        │
   └─────────────────────④首帧──────────────────────────⑤视频
                                                              │
                                                   ⑥角色配音（人工录制+裁尾）
                                                              │
                                                  ⑦字幕生成（由 VO 时间轴反推）
                                                              │
                                                      ⑧音画同步校验
                                                              │
                                                   ⑨音频工程（混音母带）
                                                              │
                                                   ⑩最终合成（烧字幕+去水印）
```

| 阶段 | 输入 | 动作 | 产物 | 关键规则 / 脚本参考 |
|---|---|---|---|---|
| ① 剧本解析 | 01_剧本/*.md | 切分幕、抽取人物与台词 | 结构化剧本 JSON | 台词逐字保留，不改写 |
| ② 分镜表 | 剧本 JSON | 生成 8 列分镜 | 02_分镜/*.md | 含连续性基线、制作约束、待确认项 |
| ③ 镜头清单 | 分镜表 | 输出每镜：场景/帧数/VO 落点 | episode_config.yaml 的 `shots` | 每镜统一 **121 帧 @24fps = 5.0417s**（VideoGen 实测固定值） |
| ④ 首帧生成 | 分镜画面描述 | 生成每镜首帧 | 03_首帧/EPXX_0X.png | 9:16 写实；禁水印/塑料皮肤；脸异常整张重生成（禁 inpaint）；每镜 2 候选 |
| ⑤ 视频生成 | 首帧 | 图生视频 | 04_视频镜头/EPXX_0X_video_v1.mp4 | 121 帧；**提示词「画面渐黑」可能不渲染 → 抽末帧补 `fade=t=out`** |
| ⑥ 角色配音 | 台词 | **人工剪映录制** → 裁尾 | 05_配音/01_正式语音素材/*.wav | **禁 AI 音色**；剪映导出后裁掉尾部空白轨道 |
| ⑦ 字幕生成 | VO 时间轴 | 由落点反推 .ass | 07_字幕/EPXX_字幕.ass | 见第四节 4 项自动检查 |
| ⑧ 音画同步 | VO + 视频 | 校验人声爆发点=落点 | 同步报告 | 误差 < 0.2s；最长静默须=剧本设计停顿 |
| ⑨ 音频工程 | VO + 音效/BGM | 合成母带 | 06_音频工程/EPXX_混音_48k.wav | 见第五节 |
| ⑩ 最终合成 | 视频 + 母带 + 字幕 | concat+scale+delogo+烧字幕+mux | 09_最终成片/EPXX_最终成片_vX.mp4 | 见第六节 QC |

**合成命令骨架（来自 EP01 `build_ep01_final.py`）**
```bat
:: 1) 粗剪 concat（仅视频）
ffmpeg -y -f concat -safe 0 -i epXX_concat.txt -c copy epXX_concat.mp4
:: 2) 去水印 + 烧字幕 + 混音（cd 到 07_字幕 目录，用相对路径避开盘符解析 bug）
cd EPXX\07_字幕
ffmpeg -y -i ..\..\..\..\_work\epXX_concat.mp4 -i ..\..\06_音频工程\EPXX_混音_48k.wav ^
  -filter_complex "[0:v]scale=1080:1920:flags=lanczos,delogo=x=830:y=1840:w=244:h=78,subtitles=EPXX_字幕.ass[v];[1:a]afade=t=out:st=<总秒-0.8>:d=0.8[a]" ^
  -map "[v]" -map "[a]" -c:v libx264 -crf 18 -preset medium -pix_fmt yuv420p ^
  -c:a aac -b:a 192k -ar 48000 -ac 2 ^
  ..\09_最终成片\EPXX_最终成片_v1.mp4
```

## 三、配音规则

### 角色音色锁定（正式成片只用人工录制）
| 角色 | 性别/年龄 | 音色要求 | 禁用的替代 |
|---|---|---|---|
| 林晚 | 女 / 49 岁 | 成熟、平静、有生活感；对白自然克制，旁白比对白更平静（像本人回忆，禁播音腔） | F5-TTS、Kokoro、任何 AI 合成音色 |
| 丈夫 | 男 / 51 岁 | 克制、疏离、平静回避；不凶狠不提高音量，不霸总不油腻 | 同上 |

**铁律**：正式成片声音 = 剪映人工录制 WAV。**禁止**用任何 AI TTS（F5-TTS / Kokoro / edge-tts 等）替代或补全正式台词。本模板不内置 AI 配音调用。

### 人工配音交付流程（06 阶段前的准备）
1. 在剪映按「每镜一句」录制，导出 WAV 到 `05_配音/01_正式语音素材/`。
2. **裁尾静音**（剪映常导出 40.64s 固定轨道，真实语音仅占前 0.4–3s）：
   - 保留人声主体 + 末尾 **0.20s** 静音缓冲；不改动声音内容、不重新生成。
   - 参考 `trim_ep01_vo.py`：滑动窗 RMS 检测语音终点 → 截断 → 写回 `PCM_16`。
3. 文件命名：`EPXX_0X_角色_台词.wav`（如 `EP02_01_林晚_你回来了.wav`），单后缀，禁 `.wav.wav`。

### 对白先后约束
- 同一镜内两个说话人**绝不允许声音重叠**（丈夫/林晚先后开口，间隔 > 0 才算通过）。
- 跨镜旁白若超单镜窗，拆句分落相邻镜，或走「跨镜延续旁白 + 末镜定格延长」，不得为塞时长改锁定语速/音色。

## 四、字幕规则（自动检查 4 项）

字幕真源 = `07_字幕/EPXX_字幕.ass`，由 VO 落点反推生成（参考 `build_ep01_final.py` 的 `write_ass()`）。导出前须通过以下 4 项自动检查：

1. **每一句声音必须有字幕**：遍历 `05_配音/01_正式语音素材/` 每个 WAV，确认存在时间区间覆盖其（起点+offset）→（起点+offset+时长）的字幕行；缺失即报错。
2. **每一句字幕必须对应声音**：遍历每条 Dialogue，确认时间区间内存在对应角色的 WAV；无来源的字幕行视为错误（防止「嘴型对不上」）。
3. **不允许两个字幕同时占用同一位置**：同 Style + 同 Alignment 的两条字幕时间区间不得相交（libass 同位会重叠花屏）。
   - ⚠️ EP01 实测坑：丈夫「我们分开吧」(0.10–1.26) 与林晚「你回来啦」原字幕 (0.72–1.70) 冲突，必须将林晚字幕起点对齐其真实音频 (1.15s) 才解决。
4. **导出前进行时间轴 QC**：校验每条字幕起止在 `[0, 总时长]` 内；相邻字幕间隙不为负；长句（≥29 中文字）手动 `\N` 分行（libass 不自动换行，单行溢出画幅），行宽 ≤17 字/行。

### 字幕窗口与人工配音对齐铁律（2026-10-04 增补，EP02 镜10/12 实证）
- **字幕窗口由最终正式人工配音的真实起止时间确定**：先把每句正式配音录好、裁尾静音、确认真实时长，再据此反推字幕起止；**不得先预设字幕窗口、再反过来要求人工配音故意拉长 / 放慢 / 加拖音以填满该窗口**。
- 字幕 **起始**：可在人声起点前 **0–0.30s** 出现（允许略早便于预读），但不得晚于人声起点超过 0.20s。
- 字幕 **结束**：可比人声结束晚 **0.20–0.40s**（给尾音 / 气口一个收束感），随后随即消失。
- **禁止「字幕空窗」**：字幕窗口显著长于真实人声（如人声 3.5s、字幕窗 7.7s），导致人声结束后字幕仍滞留 4s 以上的，一律判为不合格。
- 实证：EP02 镜10 / 镜12 人工录音约 3.5s（正常自然语速），原字幕窗误设为 7.4/7.7s 产生 3.8–4.1s 空窗；已据真实人声边界收紧字幕尾至「人声结束 +0.30s」，空窗消除，QC 通过。

**字幕样式基准**（直接复用 EP01 .ass 的 Styles）：Dialogue 56px / Title 64px / Note 42px，底部对齐 MarginV 300，微软雅黑。

## 五、音频规则

### 正式 WAV 规格（强制）
- **采样率 48 kHz**、**位深 16 bit**、**声道 立体声（2ch）**。
- 所有进入成片的正式配音、母带均须满足此规格。
- **禁止**：24 kHz 单声道 AI 音频进入成片（任何 AI TTS 输出一律不得作为正式声音）。

### 音频工程（09 混音，参考 `build_audio.py`）
1. 读取 VO：非 48k 源先 `resample_lin` 重采样到 48k；立体声下混进单声道总线时先 `mean(axis=1)`（剪映导出为立体声，混音总线为单声道时须下混，源文件不动）。
2. **重叠检查**：同一镜内各 VO 区间不得交叠（间隔 > 0）。
3. 分层合成：人声(LEVEL 0.90) + 动作音效 + 场景环境床 + 低存在感 BGM（人声出现时 ducking 0.30）。
4. 立体声化（环境/BGM 加 ~11ms 微延迟展宽），**软限幅**避免数字削波，峰值归一 **0.89（≈ -1.0 dBFS）**。
5. 输出母带 `06_音频工程/EPXX_混音_48k.wav`（48k / 16bit / stereo）。

## 六、成片 QC（输出前必检）

| 检查项 | 标准 | 方法 |
|---|---|---|
| 视频分辨率 | **1080×1920** | `ffprobe` 查 width/height（EP01 源曾为 1080×1916，须先 `scale=1080:1920` 再 delogo，否则越界） |
| 音频规格 | **48 kHz / 16bit / stereo** | `ffprobe` 查 sample_rate/bits/channels |
| 音画同步 | 人声爆发点 = 计划 VO 落点，误差 < 0.2s | 波形+抽帧比对；重建前后音频 MD5 应逐位一致（证明只动字幕/视频未动音频） |
| 字幕同步 | 字幕窗起止由人工配音真实声边界确定：起≤声起+0.2s（可略早0–0.3s）、尾=声尾+0.20~0.40s；无空窗（字幕滞留>0.5s无声音即不合格），满足第四节 4 项 | 抽帧（如 0.6s / 1.4s）肉眼确认无双行花屏；按 VO 落点比对字幕尾差 |
| 角色一致性 | 脸/服装/道具跨镜连续（林晚 LW-C01、棕包左肩、灰箱右手、旧本子笔迹等） | 逐镜核对首帧与连续性基线 |
| 文件完整性 | 09 成片帧数 = 镜头数×121；时长 = 镜头数×5.0417s；无缺镜、无乱序 | `ffprobe` 帧数 + 目录清点 |
| 电平 | 峰值 ≤ -1.0 dBFS，无削波 | 混音阶段软限幅 + 归一 |

**发布前**：去水印 `delogo=x=830:y=1840:w=244:h=78`（WorkBuddy 生成器固定坐标；**换生成器须重新抽帧定位**）。旧版归档为 `EPXX_最终成片_vX_old.mp4`，正式版不覆盖旧文件。

## 七、可复用配置文件 `episode_config.yaml`

见同目录 `episode_config.yaml`。**之后生成下一集只改 4 个字段**：
`episode`（集数）、`script_path`（剧本）、`shot_count`（镜头数量）、`shots[].vo[].audio`（配音文件）。

## 附录：EP01 实测坑（必读，避免重蹈）

1. **视频分辨率 1080×1916 ≠ 1920**：delogo 越界报 `Invalid argument`，必须先 `scale=1080:1920`（纵向 0.21% 拉伸，肉眼无损）再 delogo。
2. **生成器水印坐标固定但换工具失效**：x=830/y=1840/w=244/h=78 仅对当前 WorkBuddy 生成器成立；换生成器/模型必须重新抽末帧定位。
3. **剪映导出尾静音**：约 40.64s 固定轨道，真实语音只占前段 → 必须裁尾，否则混音出现数秒空白。
4. **立体声 vs 单声道总线**：剪映 WAV 是立体声，混音总线单声道 → `add_at` 前 `mean(axis=1)` 下混（源文件不动）。
5. **字幕同位重叠花屏**：两个同 Style 同位置字幕时间相交会重叠，生成后必须做「同位置冲突」检查（见第四节第 3 项）。
6. **长句不自动换行**：libass 对 ≥29 中文字单行不折行 → 手动 `\N`，行宽 ≤17 字。
7. **字幕相对路径坑**：`subtitles=` 滤镜含盘符冒号会解析失败 → `cd` 到字幕目录用相对文件名；`fontsdir` 转义会被 shell 打碎，直接去掉让 fontconfig 自找微软雅黑。
8. **跨镜旁白**：单镜 121 帧固定，长旁白超窗时拆句分落相邻镜或走跨镜延续，严禁为塞时长改语速/音色。
